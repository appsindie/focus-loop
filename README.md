# Focus Loop

A no-account, ad-light Pomodoro and focus timer for iOS + Android (React Native / Expo).

**Gate 0 decision**: `docs/research/OPPORTUNITY_DECISION.json`  
**Factory state**: `FACTORY_STATE.json`

## Product

- **Idea**: I01 Focus Loop — niche N01 Pomodoro / focus timer.
- **Target users**: Adults with ADHD, remote workers, students, and knowledge workers who need friction-free focus sessions.
- **Core job**: Start a timed focus session and avoid phone distraction until the timer ends.
- **Wedge**: Forest feels childish, Focus To-Do is bloated, OS timers lack streaks/stats. Focus Loop is minimalist, no-account, and adult/ADHD-focused.
- **North star**: D30 retention >= 42% and Month-9 Net Monthly Contribution >= $2,000.

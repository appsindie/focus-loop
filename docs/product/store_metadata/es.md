```
Focus Loop es un temporizador pomodoro pensado para mentes TDAH y trabajadores del conocimiento: empieza una sesión de deep work con un toque y la app corre todo el ciclo enfoque–descanso. Sin cuenta, sin configuración.

CÓMO FUNCIONA
Un toque y el temporizador arranca. Al terminar el enfoque, el descanso empieza solo — y el ciclo continúa. La técnica pomodoro sin ajustes.

HECHO PARA TDAH
Quien busca una app de enfoque para TDAH no necesita otra racha que romper. Focus Loop usa metas semanales: 4 días de enfoque por semana, y un mal día no borra tu progreso. Pausar o terminar antes también cuenta.

Úsalo como temporizador de estudio, timer de deep work o temporizador de concentración. Empieza desde el widget y mira el tiempo sin abrir la app.
```

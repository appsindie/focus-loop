- Description:
```
Focus Loop — помодоро-таймер для людей с СДВГ и работников умственного труда: начните глубокую работу в одно касание, а цикл фокус–перерыв приложение поведёт само. Без аккаунта и настроек.

КАК РАБОТАЕТ ЦИКЛ
Одно касание — и таймер фокуса запущен. Когда фокус заканчивается, перерыв начинается сам, затем цикл продолжается. Техника помодоро без возни.

ДЛЯ СДВГ
Тем, кто ищет приложение для фокуса при СДВГ, не нужна ещё одна серия, которую обидно сорвать. Focus Loop работает с недельными целями: 4 фокус-дня в неделю, и плохой день не обнуляет прогресс. Закончить раньше — тоже считается.

ТАЙМЕР ДЛЯ УЧЁБЫ И РАБОТЫ
Как таймер учёбы перед экзаменами, таймер глубокой работы для письма и кода или таймер концентрации для чтения. Запуск из виджета, время видно на экране блокировки.

• Помодоро в одно касание с авто-перерывами
• Виджет и Live Activity на экране блокировки
• Недельная цель, которая прощает
• История и недельная статистика
• Светлая и тёмная темы, работает офлайн
• Бесплатно, Plus по желанию (год или навсегда)
```

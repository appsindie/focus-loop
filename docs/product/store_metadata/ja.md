- Description:
```
Focus LoopはADHDの人とナレッジワーカーのためのポモドーロタイマー。ワンタップでディープワークを始め、集中と休憩のループをアプリがまわします。アカウントも設定も不要。

ループのしくみ
タップするだけで集中タイマーがスタート。集中が終われば休憩が自動ではじまり、また次の集中へ。面倒な設定のないポモドーロテクニックです。

ADHDのために
集中アプリを探す人に、また切れてしまうストリークはいりません。Focus Loopは週間ゴール制 — 週4日の集中を目指し、悪い一日があってもリセットされません。早めに終えてもカウントされます。

勉強・作業タイマーとして
試験勉強のタイマー、執筆やコーディングのディープワークタイマー、読書の集中タイマーに。ウィジェットから開始でき、残り時間はロック画面に表示されます。

・ワンタップのポモドーロと自動休憩
・ホーム画面ウィジェット＋ロック画面Live Activity
・悪い日をゆるす週間ゴール
・履歴と週間レポート
・ダーク/ライトテーマ、オフライン対応
・無料、Plusは年額または買い切り
```

# `@appsindie/react-native-notification` Integration Notes

## Purpose
Reusable push-notification journey package built on Firebase messaging and AppsIndie cores.

## Use when
- Feature requires remote push handling and notification center/history UX.
- Team needs a standard notification setup across apps.

## Compatibility checkpoints
- Firebase messaging SDK and Expo/RN compatibility.
- Device/app permission flow readiness for push notifications.
- Dependencies for list rendering, navigation, and state management.

## Integration evidence
- Push receive/open behavior verified on target platforms.
- Notification history and configuration screens verified.
- Permission denied and token refresh edge cases handled.
